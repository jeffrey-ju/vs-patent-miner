# Innovation Categories Reference

## Category Definitions

### 1. AI/ML Innovation

**Definition**: Novel applications of artificial intelligence or machine learning that go beyond standard library usage.

**Indicators**:
- Custom scoring or ranking algorithms
- Novel prompt engineering techniques
- Unique model architectures or fine-tuning approaches
- Multi-dimensional evaluation systems
- Conversational AI with sophisticated state management

**Code Patterns**:
```python
# Python
class *Signature(dspy.Signature)  # DSPy signatures
class *Module(dspy.Module)        # DSPy modules
def calculate_*_score()           # Scoring functions
def *_alignment()                 # Alignment calculations
```

```typescript
// TypeScript
function use*AI()                 // AI hooks
interface *Prediction             // Prediction types
```

**Example Innovations**:
- Multi-dimensional alignment scoring with scope-aware weighting
- Five-pillar competency assessment system
- Bilingual OKR quality validation

## Novelty Assessment Criteria

### High Novelty (80-100)
- No existing patent covers this approach
- Significantly different from standard implementations
- Solves a problem in a new way
- Combines multiple techniques uniquely

### Moderate Novelty (60-79)
- Builds on existing approaches with significant improvements
- Novel combination of known techniques
- Unique application to a specific domain

### Low Novelty (40-59)
- Incremental improvement on existing approaches
- Common pattern with some customization
- May need additional differentiation

### Not Patentable (0-39)
- Standard library usage
- Common design pattern
- Well-documented prior art exists
